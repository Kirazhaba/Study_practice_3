# Доска публикаций

Веб‑приложение для просмотра и создания публикаций

## Способ запуска

1. Убедитесь, что установлены Node.js и браузер.
2. Создайте папку проекта, поместите в неё файлы: `index.html`, `style.css`, `app.js`.
3. Откройте `index.html` в браузере.
4. Нажмите «Посмотреть список публикаций» для загрузки данных; заполните форму для создания новой публикации.

## Результаты проверки

- Загрузка списка публикаций: успешно (отображаются до 5 записей с заголовком и текстом).
- Создание публикации: успешно (эмуляция POST‑запроса, вывод ID и заголовка новой записи).
- Обработка ошибок: выводятся сообщения при сетевых сбоях или пустых полях формы.
